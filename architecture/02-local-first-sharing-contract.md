# 로컬 우선 공유 계약

개인 보드는 기기 안에 저장하고, 사용자가 **공유하기**를 누른 항목만 팀 서버에 보낸다.

1. 개인 업무, 메모, RAG 원본은 브라우저 저장소 또는 향후 로컬 DuckDB에 둔다.
2. 공유를 선택하면 `publication` 이벤트만 대기열에 넣는다.
3. 공지 읽음과 공유 업무 수정도 독립된 이벤트로 남긴다.
4. 서버는 `event_id`를 기준으로 중복을 막고, 권한을 확인한 뒤 팀 보드에 반영한다.

`db/migrations/002_local_first_sync.sql`은 공유 서버의 수신 원장과 공지 읽음 기록을 만든다. 이 마이그레이션은 로컬 DB나 DuckDB를 만들지 않는다. 로컬 실행 파일과 DuckDB/RAG 패키징은 다음 단계이며, 지금 제공한 웹 MVP는 브라우저 `localStorage`를 개인 저장소로 쓴다.
