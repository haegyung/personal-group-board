# GitHub와 웹서비스 런타임의 경계

이 저장소는 비공개 GitHub 저장소에서 소스, 아키텍처, 검증 워크플로를 관리한다.
GitHub Actions는 정적 검사를 실행하지만 장기 실행 API나 데이터베이스를 호스팅하지 않는다.

웹서비스를 실제로 공개할 때는 다음을 별도 환경에 배포한다.

- 웹 프론트엔드
- API와 작업 워커
- PostgreSQL + pgvector
- OAuth 비밀값과 알림 공급자 설정

개인 DuckDB와 개인 RAG 원문은 사용자의 로컬 환경에 남기며, 비공개 GitHub 저장소에도 넣지 않는다.
